Gilman

This visualization shows every performance at the Gilman Street Project between 1986 and 1994. Node size reflects the number of shows; edge thickness indicates shared performances.

How to use this visualization
  • Click a node for band details and connections.
  • Search to filter the network to a specific band.
  • Reset to return to the full network.
  • Export to save as PNG.
  • Drag & Zoom to navigate. With the network focused, the arrow keys pan and + / − zoom.
  • Colors represent communities — bands that frequently played together.
  • Size reflects total co-performances across the network.
  • Every band's connections are also listed as text under Band details.
